# 权限边界与已知限制

本版目标是防止普通研究工作中的遗忘、错配、覆盖、误判完成和日志缺失。它不是一个承诺可以安全运行恶意比赛代码的系统。

## 已实现的程序约束

登记先于启动；参数数组执行、不用 shell=True；限定代码编辑路径；冻结受保护 evaluator 哈希；独立训练/评估目录；正式/测试状态检查；训练量与曲线检查；同协议比较；Champion 晋升接口；常见凭证文件排除；训练进程环境变量白名单；独立运行 HOME；终态产物完整性校验；预算与并发事务。

环境版本通过 importlib.metadata 记录；不保证外部系统库、驱动、硬件和非确定算子可复现。GPU 秒是分配量估计，不是 GPU 遥测。本地实验不默认上传数据或安装第三方比赛代码。可选 Kaggle 远端启动需要显式执行参数，边界见 [Kaggle 工作流](RESEARCH_AND_KAGGLE.md)。

## 不应从这些约束推导出的保证

同一操作系统用户通常仍能直接读写别的文件。把账本放在另一目录不等于权限隔离；chmod 和 SQLite 触发器也不是对抗拥有文件修改权的恶意进程的安全边界。

Codex 的 read-only sandbox 不等于只能读取提供的少量上下文。适配器在独立临时目录提供源码和选中证据，默认不注入档案，但硬性阻止读取冷档案需要 OS/容器身份隔离。

训练代码与评估器仍是本地进程。恶意代码可能读取验证集、产生虚假日志、访问网络或试图修改控制器文件。哈希检查能发现一些修改，但不能证明一次研究没有泄漏或作弊。示例训练只读取 train 数据，真实任务必须自行维持这个边界。

默认排除的密钥文件名只是误泄漏预防，不能识别所有命名方式或硬编码密钥。不要把凭证写进参数、日志或普通源码。Codex 进程需要本机已有认证，其环境不能像训练进程一样完全清空；本版不会保存认证环境内容。

## 更强部署边界

需要运行不可信代码时：把 controller/store 放在独立服务用户下；worker 容器只得到源码只读挂载、必要训练数据、输出目录和资源额度；评估器由另一个权限更小的进程读取验证集；默认关闭网络；不挂载 Codex 认证和整个用户 HOME。训练不能拥有直接修改 ledger/Champion/evaluator 的权限。

这些是明确的部署要求，不是本压缩包已经替你完成的容器隔离。本版不包含未经验证的“安全 Docker 一键部署”。

## 中断与恢复限制

v0.1 覆盖 Linux SIGTERM、SIGKILL 后可识别子进程的恢复。v0.2/v0.3 在原生 Windows 检查了本地实验与子进程超时；三项 POSIX 专用信号/硬杀测试在 Windows 跳过。无法可靠验证残留进程身份时不会盲杀。

进程创建到 PID 写入账本之间存在极短窗口；控制器恰好被硬杀时可能留下尚未登记的子进程。正常退出会清理所建进程组，但主动脱离 session 的恶意后代不在本地进程树保证内。需要更强保证应使用 worker 服务/cgroup/容器作业管理。

recover 不会重建尚未上报的曲线，也不自动续训。断电、磁盘满或存储损坏可能导致最后一部分日志未保存，应用层不能取代存储备份。

## 研究与预算限制

min_improvement 不是显著性检验。固定 holdout 也会因反复试验而过拟合。不同优化器不能仅凭同一学习率的一次对照下普遍结论。自动参数归因不是本版功能。

实验时间预算保护的是运行预留与子进程 deadline；快照、哈希和清理有额外开销。控制器死亡时保守计入预留，可能比实际使用更高。Codex 只有限轮数与超时，没有 token/费用总额硬上限。

SQLite 实现面向单机本地磁盘，不宣称支持网络共享盘上的可靠多节点写入。源码快照不是外部数据备份。若数据必须升级，应建立新 store/评估协议，而不是直接修改元数据绕过对比限制。

模块登记/导入不执行代码，语法通过不等于运行或论文忠实度通过。源码绑定也不能证明 forward 调用了它。任务专用 preflight 是固定脚本的检查结果，其探针范围需要自己审查；将脚本加入 protected_files 防止普通提案改写检查。模块案例保留人工判断与原事实，不能自动证明因果收益。
