# v0.3 review · 2026-10-08

本次逐项检查了模块登记、变体关系、跨赛事绑定、Codex 上下文、案例、导入导出、preflight、旧版账本与安装包。review 由当前实现者完成，未声称独立审查或真实模型评测。最后完整测试为 138 项：135 通过、3 项平台跳过、0 失败/错误。

## 已落实的检查与修复

| 检查点 | 最终行为与验证 |
|---|---|
| 实现来源 | 登记冻结实际源码，检查语法而不执行；记录来源、许可、贡献者与局限，不接受卡片自称 validated。来源代码、卡片及额外文件修改均能被校验发现。 |
| 变体关系 | 新版本追加父版本，拒绝缺失祖先；导入校验祖先顺序，完整检查可发现环。差异来自实际文件。 |
| 适配继承 | 子分支保留父实验已改过的文件；分别核对原始、修改前与最终哈希。测试覆盖库离线时继续继承。 |
| 实验账本 | 新增不可修改的来源绑定，报告覆盖绑定；原有配置、指标、预算、Champion 和评估门槛继续有效。 |
| 共享索引异常 | 索引暂时不可写时保留来源绑定与可用实验，追加异常事件；SQLite 写入失败不会把完整快照标为失败，构造数据库失败会释放句柄。 |
| 条件性案例 | 创建时验证原实验，冻结事实与人工解释；smoke/失败只能 undecided，同协议基线才可比较。导出和查阅都检查案例档案与数据库一致，并核对模块版本。 |
| 文件句柄 | Windows 测试发现只用 SQLite context manager 不会关闭连接；案例/使用索引读取改为显式 closing，临时账本删除不再失败。 |
| 复制与导出 | 原始源码的缓存排除发生在冻结前；冻结后的额外文件属于完整性异常。导入拒绝改过的源码、非法路径、错误版本案例及清单之外的材料。 |
| 模型上下文 | 默认不扫描库，只向明确选中的模块提供实际源码和有限案例；大案例历史缩减提示体积但不删记录，不阻止读取实现。响应不能新增未选中的版本或未经再次选择重置父实现，通过子进程 fixture 验证源码可读取。 |
| preflight | 验证报告格式、布尔结果、唯一检查名和限定范围；检查失败、超时或改源码阻断训练。启用检查时核对训练前后源码，三个阶段的 KH_SOURCE_ROOT 指向实际副本。 |
| 协议兼容 | 启用 preflight 时命令进入协议哈希；旧策略不含该字段时哈希保持原样。旧报告无模块字段且实际无绑定时仍可对账。 |
| 安装包 | 离线构建 wheel，30 个核心/资源文件与当前源码逐字节一致；确认独立目录导入的是 wheel 内容，并实际运行两套 CPU 示例。 |
| 私有参考 | 本地登记 26 段文档实现，逐字节对照原文并核对原文 SHA；私有库、原文及提取源码不进入提交。 |

## 结果与边界

旧版真实账本的 6 次实验、8 个研究节点通过深度检查，6 个协议哈希重算一致，原报告对账通过，原有表内容未被改变。安装包运行的模块示例在固定合成任务上得到线性基线 MSE 0.875992915、二次变体 MSE 0.0000309243；在第二个任务记录执行成功但无对照的 undecided 案例。未将该结果扩大为跨领域效果或 Kaggle 成绩。

源码绑定证明文件来源与适配，不自动证明 forward 采用了模块；preflight 是已冻结检查脚本的具体探针结果，不等于论文忠实度或因果收益。导入的案例保留来源，原账本不可用时明确降为 unavailable；无数字签名，也不作为抵抗恶意材料的认证系统。核心面向可信研究代码，权限边界见 [限制说明](SECURITY_AND_LIMITS.md)。

三项跳过是 POSIX SIGTERM、Linux SIGKILL/进程身份恢复和 POSIX 符号链接测试。真实 Codex 模型调用、YUE 模块 PyTorch 前后向、GPU 训练和远端 Kaggle 作业未执行。Kaggle CLI 的 v0.2 实连验证范围保留在原报告，不重复包装成 v0.3 训练验证。
