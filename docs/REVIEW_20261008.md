# v0.2 实现后 review

日期：2026-10-08。范围：本次实现后的代码自 review、自动化测试、原生 Windows 执行、安装包闭包和 Kaggle CLI 实连。
设计参考 Kaggle Agent v1.37.1，继续使用本项目实验内核。公共 Skill 自动匹配与下载未纳入实现。

## 检查的边界

- **单一事实来源**：研究图派生实验数值，解释追加保存，不写回原实验指标。远端 Notebook 完成不晋升 Champion。
- **研究一致性**：新节点只引用已有父节点，修改要求当前 revision；日志观察不使研究 revision 失效。
- **真实父版**：选定父版同时决定配置、传给模型的源码和上下文。以不同源码标记的真实 CPU 实验及 CLI 替身验证。
- **比较边界**：失败/测试/异协议/损坏产物不成为自动父版。回放只使用已揭示结果，不创造新分支或证明未来收益。
- **CLI 边界**：参数数组、超时、能力探测、输出脱敏、别名环境隔离；只读采集和源码下载不执行外部 Notebook。
- **异步边界**：精确 Notebook 版本、全 ref 重复启动拦截、未知状态保留、显式人工恢复关联。
- **证据闭包**：源码/产物/评估文件/研究材料指纹、SQLite、报告数字和覆盖检查；安装包模块与源码逐字比对。

## Review 中修正的问题

1. 本机 Kaggle 2.2.4 的 pages 可选位置参数与子解析器存在歧义。使用源码中支持的 competition_opt 选项，实连成功。
2. JSON 输出可能夹带分页游标和警告。分离 data/notices，并对忽略 page-size 的索引结果再次限定。
3. 资料采集接入 store 的路径漏了 dumps 导入。增加 CLI 到同一账本及压缩上下文的端到端测试后修正。
4. 本地告警重复 tick、终态旧错误文本、研究 revision 被监控扰动分别处理；监控提示不改写科学结果。
5. 上传源的凭据检测移到复制之前，并改为分块扫描，覆盖超过 2 MB 的源文件。
6. Notebook ref 被固定到实际版本；没有版本号/传输不确定时禁止自动重投，增加人工核实版本的恢复入口。
7. 账号别名变化不能绕过同一 ref 的活动任务拦截。
8. 研究资料文件使用路径和 SHA-256 绑定，修改原始响应会使完整性检查失败。
9. 旧 POSIX shebang 的四项 Codex 替身测试改为解释器前缀，在 Windows 上实际运行；验证选中父版的源码字节。
10. 验证临时目录定位到工作区；Windows 进程终止后等待回收，并为受限环境增加自有进程句柄终止兜底。
